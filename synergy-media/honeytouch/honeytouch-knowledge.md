# ハニタッチ（HONEYTOUCH）

> 配置先: `synergy-media/honeytouch/honeytouch-knowledge.md`

---

## 1. サービス概要

交通系ICカードをタッチするだけで「抽選」「ポイント付与」「スタンプラリー」を実施できる販促システム。専用カードやアプリの準備が不要で、その場で即参加できる点が中核価値。

**ポジショニング**：商業施設・鉄道事業者向けの来館促進／回遊促進ツール。会員獲得の摩擦をゼロにすることが最大の売り。

**キャッチコピー（公式）**
- 交通系ICカードを活用した顧客サービス向上システム
- 交通系ICカードをタッチするだけ！

---

## 2. 技術的な仕組み

FeliCa の **IDm（製造ID）** を読み取り、匿名IDとしてサーバー側で管理する方式。JR東日本の公開資料でも「IDmを利用したマーケティングシステム」として登録されている。

- IDm は ICチップ製造時に書き込まれる書き換え不能な固有ID（8byte / 16桁）
- 氏名・電話番号などの個人情報を取得しない → 事前登録不要・匿名参加が成立する根拠
- 同一IDmの複数回タッチを検知できるため、不正参加を防止できる
- 改札ログを利用した「特定駅降車者のみ対象」の絞り込みも可能（※要事前許可）

> **設計上の含意**：UIに「会員登録」「ログイン」の概念が存在しない。フォーム設計・個人情報同意画面は不要。これがスマート抽選や一般的な販促アプリとの決定的な差。

## 3. 対応カード

Suica / PASMO / ICOCA / TOICA / manaca / nimoca / Kitaca / SUGOCA / PiTaPa / はやかけん

スマートフォン内に登録されたモバイル交通系ICカードも利用可。地方カード（PASPY等）併記の事例もあり。

---

## 4. 提供機能（3モード）

| モード | 内容 | 典型的な使われ方 |
|---|---|---|
| 来場抽選 | タッチで抽選、当選時にクーポン／景品引換券をプリント | 施設の周年祭、季節キャンペーン |
| 来場ポイント付与 | 来場ごとにポイント、規定到達でクーポン発券 | リピート促進。1日1ポイント制が多い |
| スタンプラリー | 複数台の端末を回遊して達成 | 複数施設・エリア横断型 |

**演出のバリエーション**：単純抽選のほか、ポイント到達でスロットを回す等のゲーム演出を挟む事例あり（広島アルパーク：5ポイントでスロット、絵柄が揃えば景品）。

---

## 5. 訴求ポイント（公式の6特徴）

1. 事前登録不要
2. 匿名のまま利用可能（心理的抵抗が低い）
3. 発行済みカードが利用可能（垂直立ち上げが可能）
4. 簡単操作
5. 1カード・マルチユース
6. 過去の利用履歴を管理（One to One 対応）

**導入側メリット**：会員獲得が容易／One to Oneサービス提供／効果的プロモーション展開（意図した経路への顧客誘導）／顧客行動特性の把握／システム導入コストの低減（複数企業でのシステム共有）

## 9. 表記・商標ルール ★制作物では省略不可

- 正式表記：**ハニタッチ**（×ハニータッチ ×HoneyTouch ×ハニタッチ®）

- 「各許諾または承認事業者の都合により、予告なくカードが交換されることがある」旨も併記

## 10. 用語集

| 用語 | 定義 |
|---|---|
| IDm | FeliCaチップ固有の製造ID。ハニタッチの匿名ID基盤 |
| 匿名ID | IDmをサーバー管理して個人を特定せず識別する仕組み |

| 1カード・マルチユース | 1枚のICカードで複数サービスを受けられる状態 |

## 11. デザイン作業時の注意

- **会員登録・ログイン画面は存在しない。** 画面設計時に認証フローを想定しないこと
- 主要な出力物は「その場でプリントされる紙のクーポン／引換券」。デジタル完結ではない
- 利用者導線は「端末の前に立つ→タッチ→結果表示→印刷」の数秒。**待ち時間UIより即時性の演出**が要件
- 設置場所はサービスカウンター・特設カウンター等の屋内。掲示物（ポスター・POP）とセットで設計されることが多い
- カード各社のロゴ使用には別途許諾が必要な可能性が高い。安易にロゴを並べない
