# スマート抽選（スマート抽選会）

> 配置先: `synergy-media/smart-lottery/smart-lottery-knowledge.md`
> 最終更新: 2026-08-07 / 出典: 公式サイト・イプロス・自社ニュース

---

## 1. サービス概要

従来のガラポン（回転式抽選機）に代わる、スマホ完結型の抽選システム。抽選券に記載された二次元コードをスマホで読み取ると即座に抽選が始まり、その場で結果が出る。

**キャッチコピー（公式）**
- 従来のガラポンに代わるスマホを使った抽選会
- スマホ内で抽選会を行うことで、どこにいても気軽に参加できる"スマートな"抽選方式

**起源**：コロナ禍の「密集・密閉・密着」対策として設計された経緯がある。現在は3密対策よりも運営効率・体験価値の文脈で訴求されている。

---

## 2. 仕組み

1. 買上等の条件を満たした来館者に**抽選券を配布**
2. 抽選券記載の**二次元コードをスマホで読み取る**
3. スマホ画面上で抽選が実行され、**即時に結果表示**
4. 当選者のみが景品交換所へ（または デジタルクーポンが発券される）

**アプリ不要。** ブラウザ完結。

> ※スマホ未所持・二次元コード読取不可・ネット接続不可の来場者向けに、景品交換所（スマート抽選会お客様対応特設会場）に貸出用スマホを準備する運用がある。

---

## 3. ラインアップ（3型）

| 型 | 内容 | 備考 |
|---|---|---|
| 景品交換所設置型 | 当選者のみが交換所に来場して景品受取 | 公式サイト掲載 |
| デジタルクーポン発券型 | 当選時にデジタルクーポンを発券、スマホ内で完結 | 公式サイト掲載 |
| 景品宅配型 | 当選景品を配送 | イプロス掲載。公式サイト未掲載のため現行提供か要確認 |

---

## 4. 訴求ポイント（公式の3特徴）

1. **スマホ内でスマートに完結**
2. **ガラポンと応募型のハイブリッド的ポジション** … 即時性（ガラポン）と手軽さ（応募型）の中間
3. **二次元コードで簡単に参加可能**

**運営側メリット**
- 当選者のみが交換所に来るため**会場混雑が発生しない**
- 抽選会場の設営が不要、**スタッフ人件費を削減**できる
- イベント特性に合わせたカスタマイズが可能

**施策思想（重要）**
公式資料に明記されている考え方 ── 「多くの人を集める」施策ではなく、**来館済みの客の購買意識を高め、100円でも多く買ってもらう**ための施策。集客ではなく客単価向上のツールとして位置づけられている。訴求資料を作る際はここを外さないこと。

## 6. ハニタッチとの使い分け

同社内で最も混同されやすい2製品。差分を明確に。

| | ハニタッチ | スマート抽選 |
|---|---|---|
| トリガー | 交通系ICカードのタッチ | 抽選券の二次元コード読取 |
| 専用ハード | **必要**（設置端末） | **不要** |
| 参加条件 | ICカード所持者なら誰でも | 抽選券の配布を受けた人（買上条件等） |
| 参加場所 | 端末の前 | どこでも |
| 結果の出力 | 紙のクーポン／引換券をプリント | スマホ画面 → 交換所 or デジタルクーポン |
| 個人情報 | 取得しない（匿名IDm） | 取得しない（券ベース） |
| 主目的 | 来館促進・回遊促進 | 客単価向上・購買意識喚起 |
| 運用期間 | 中〜長期・常設寄り | 短期・イベント連動 |

## 7. 表記ルール

- 正式表記：**スマート抽選**
- ただし公式サイト内・イプロス・実績記事では **「スマート抽選会」** も併用されている
  → **どちらが正なのか社内確認が必要。** 現状は文脈により揺れている
- 二次元コード表記：公式サイトの説明文では「QRコード」、イプロス掲載文では「二次元コード」
  → **「QRコード」はデンソーウェーブの登録商標。** 制作物では原則「二次元コード」を推奨し、QRコード表記を使う場合は商標注記の要否を確認すること

## 8. 用語集

| 用語 | 定義 |
|---|---|
| 抽選券 | 二次元コードが印字された参加券。買上条件等で配布 |
| 景品交換所 | 当選者が景品を受け取る場所。貸出スマホも設置 |
| デジタルクーポン | 当選時にスマホ内で発券される電子クーポン |
| ガラポン | 従来型の回転式抽選機。本サービスの置換対象 |
| 応募型 | 後日抽選方式。即時性がない従来手法 |

## 9. デザイン作業時の注意

- **紙（抽選券）とデジタル（抽選画面）の両方が制作対象**になる。片方だけで完結しない
- 抽選券は二次元コードの読取成功率が最優先。**印刷サイズ・コントラスト・余白（クワイエットゾーン）を削らない**
- 抽選画面はイベント世界観に合わせたカスタマイズ前提。クリスマス・周年など**季節テーマの差し替えが頻発する**構造で設計すること
- ユーザーはその場で立ったまま片手操作。**縦持ち・片手・短時間**が前提
- 「はずれ」画面の体験設計が重要。当選率は施策ごとに異なるが、大半の参加者が見るのははずれ画面
