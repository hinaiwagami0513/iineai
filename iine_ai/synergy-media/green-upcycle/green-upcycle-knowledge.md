# グリーンアップサイクル®（GREEN UPCYCLE）

> 配置先: `synergy-media/green-upcycle/green-upcycle-knowledge.md`
> 最終更新: 2026-08-07 / 出典: 公式サイト・PR TIMES・CLASS1 ARCHITECT・エコプロ

---

## 1. プロジェクト概要

衣料廃棄物を独自の製造技術でフェルト状のシート・パネルに再生し、プロダクトとして再活用する素材事業。**2022年8月立ち上げ／2022年9月16日プレスリリース。**

**キャッチコピー（公式）**
- 「燃やさない」という選択で、衣料に新たな価値を生み出す
- 燃やす？埋める？捨てられる服で新たな価値を！

他2サービス（ハニタッチ／スマート抽選）が販促システム事業であるのに対し、これは**素材・プロダクト事業**。ドメインが完全に異なるため、語彙・トンマナを混ぜないこと。

---

## 2. 背景となる社会課題（訴求の根拠数値）

- 国内の衣料廃棄物は**年間50万トン以上**と推計
- そのうち**90％以上**が焼却または埋め立て処分
- ポリエステル・ウール等の単素材は再生手法があるが、**現在の服の主流である混合素材は単一素材への分解ができず再利用が困難**

→ この「混合素材でも再生できる」という点が技術的な差別化の中核。

---

## 3. 事業プロセス（6工程）

| # | 工程 | 内容 |
|---|---|---|
| ① | 資源回収 | 古着、製造工程で出た端材などを回収 |
| ② | 前さばき（分解・素材分別） | ボタン・ファスナー等の付属品を除去 |
| ③ | 粉砕・裁断 | 裁断機で細かくカット |
| ④ | 反毛（はんもう） | フリース（ワタ）状に繊維を戻す |
| ⑤ | 形成（一次加工） | **独自設計の秘蔵工程**でフェルト状のシート・パネルに加工 |
| ⑥ | 製品化（二次加工） | 協力会社に依頼して製品化、自社で提供 |

**最重要の技術特徴：接着剤を使用しない。**
→ 割れる心配がない／使用後に反毛して再循環可能（半永久的な再利用）／サーキュラーエコノミーが成立する根拠。訴求資料でこの一点を落とすと差別化が消える。

---

## 4. 素材スペック

### シート
- 36判サイズ
- **薄さ0.5mmまで実現可能**
- 湾曲した箇所に使用可。カーブのある椅子・什器への貼り合わせが可能
- 1mm厚：保形性があり土は収まったまま余分な水分をろ過 → 緑化用プランターに最適

### パネル
- 36判サイズ
- 厚み **5mm / 10mm / 20mm** の3種
- 比較的軽くて強度あり
- 椅子・棚・パーテーション等のインテリア用途に適合
- パンチング加工で有孔ボード状にも加工可
- 合板の代替としての用途を想定

### 色展開（3種）

| 種別 | 原料 | 色系統 |
|---|---|---|
| デニム素材 | デニム端材等 | ネイビー系 |
| 麻素材 | 麻袋等 | ベージュ系 |
| カスタム素材 | 顧客からの廃棄衣料回収 | グレー系 |

**カスタム素材が営業上の核。** 顧客自身の廃棄衣料からオーダーメイドでシート・パネルを製造できる ＝ その企業専用の資源循環ストーリーを構築できる。

## 5. 製品ラインアップ

プランター（プランターカバー）/ トートバッグ / ブックカバー / トレー / コースター / ペンケース / ハンガー / スリーブ（コーヒーカップ用）

**建築・インテリア用途**
- 緑化用プランター（1mm厚シート）
- カウンター（1mm厚シート貼り合わせ。遠目に大理石のような表情）

**検討中の用途**
- 災害時の頭部保護カバー（シート）
- 体育館の防寒パネル（パネル）
→ 自治体との会話から出てきた汎用可能性。確定情報ではない

**流通**：ノベルティ・SDGs販促品として外部代理店経由の販売あり（「販促日本一」等）。STORESでの直販アイテムも存在。コースター卸価格170円（税抜）の実績あり。

## 7. ビジョン・語り口

- 「理解・賛同していただけるみなさんと新たな価値を創造していきたい」というオープンな協業姿勢が一貫したトーン
- 「こんな使い方どう？」と外部から提案してもらう **共創型のコミュニケーション設計**
- 将来的な目標：自治体・市民と協力し、**地域内で出た衣料廃棄物をその地域で活用する「地産地消モデル」の構築**
- 立ち上げ経緯：代表・佐藤正一が素材元企業でマーケティング顧問をしていたことが起点。もともと地域内の価値交換・資源循環への関心があった

**トーンの注意**：説教型・危機煽り型ではなく、「一緒に考えてほしい」という招待型。制作物のコピーもこの姿勢を崩さないこと。

## 9. 表記・商標ルール ★制作物では省略不可

- **「グリーンアップサイクル®」はシナジーメディア株式会社の登録商標。初出には必ず ® を付す**
- 英字表記：`GREEN UPCYCLE`（公式サイト・エコプロ出展名で使用）
  - `GREEN UP CYCLE`（スペース入り）表記が一部流通しているが**誤り**。代理店サイト等で混在
- 「アップサイクル」を一般名詞として使う場合は ® 不要。プロジェクト／素材を指す場合は必須
- 素材名として「グリーンアップサイクル®シート」「グリーンアップサイクル®パネル」と表記

## 10. 用語集

| 用語 | 定義 |
|---|---|
| 反毛（はんもう） | 裁断した繊維をフリース（ワタ）状に戻す工程 |
| 前さばき | ボタン・ファスナー等の付属品を除去する工程 |
| 一次加工 | フェルト状シート／パネルへの成形。自社の秘蔵工程 |
| 二次加工 | 協力会社によるプロダクト化 |
| サーキュラーエコノミー | 循環型経済。資源を廃棄しない前提の生産・循環システム |
| 混合素材 | 複数繊維の混紡。単一素材に分解できず従来は再生困難 |
| 36判 | シート・パネルの標準サイズ規格 |
| カスタム素材 | 顧客から回収した廃棄衣料で製造するオーダーメイド素材 |

## 11. デザイン作業時の注意

> ビジュアルの方向性（配色・レイアウト・タイポの具体則）は `green-upcycle-design-direction.md` に分離。制作前に必ず参照。

- 素材の**質感が最大の訴求要素**。写真・実物の見せ方が命綱で、CGやイラストでの代替は説得力を大きく落とす
- 色は素材由来の3系統（ネイビー／ベージュ／グレー）に限定される。**任意のブランドカラーを素材に載せられない**前提で設計すること
- 「様々な繊維が混在した豊かな表情」「遠目には大理石のよう」が語られる価値。**均一・クリーンに見せすぎると価値が消える**
- ターゲットが多層：BtoB建築・インテリア設計者 / ノベルティ発注担当 / 自治体 / 一般消費者。**誰向けの制作物か最初に確定させること**
- 他2サービス（販促システム）とはデザインシステムを共有しない。トンマナも語彙も別
